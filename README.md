# agents-pane — панель агентов для Claude

Отдельная панель рядом с чатом: все агенты, которых запустил диспетчер, без чтения переписки.

Для каждого агента видно:
- номер, статус (▶ работает, ⏸ ждёт, ✓ готов, ✗ ошибка), роль и модель (haiku / sonnet / opus);
- сколько времени прошло и сколько токенов потрачено;
- задача — начало промпта, с которым агента запустили;
- «Сейчас» — какой инструмент он вызывает и над каким файлом;
- «Ответ» — начало его последнего отчёта.

Роль определяется по описанию агента (Сценарист, Монтажёр, Ассистент, Директор), а если в описании её нет — по модели.

## Как обратиться к агенту
- Нажми на строку агента — в главном окне откроется его переписка, и следующее сообщение уйдёт ему. Кнопка «← главный чат» возвращает назад.
- Или командой: `/agent-say 2 поправь заголовок` — по номеру из панели, либо `/agent-say монтажёр …` — по роли.

`/team` — открыть панель, если её закрыли.

## Установка
```
/plugin install agents-pane --marketplace annavolkova06121-bit/claude-agents-panel
```
Затем `y`, чтобы добавить маркетплейс, и выбрать область установки.

Секретов, ключей и путей к файлам пользователя в плагине нет.
