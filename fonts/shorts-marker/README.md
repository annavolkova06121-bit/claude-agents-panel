# Shorts Marker

Шрифт для подписей, восстановленный по вашему видео: рукописные заглавные буквы маркером, как в субтитрах про вомбатов.
Строчные буквы показываются теми же заглавными (так в видео и сделано), поэтому текст можно писать как обычно.
Три начертания, подписи в цветах и в темах токсичного, лавы и моря (градиент, текстура, свечение), мягкая тень.

## Что внутри

| Файл | Назначение |
|---|---|
| `ShortsMarker-Regular.ttf` | штрих как в видео (31 КБ) |
| `ShortsMarker-Bold.ttf` | утолщённый, отступы чуть шире |
| `ShortsMarker-ExtraBold.ttf` | самый жирный, семья «Shorts Marker ExtraBold» |
| `caption.py` | рисует подпись: цвета, темы acid / lava / sea, тень (нужны Pillow и numpy) |
| `samples/*.png` | готовые образцы стилей с прозрачным фоном |
| `source/glyphs/*.png`, `source/glyphs.json` | растровые буквы и отступы: из них шрифт собирается без видео |
| `source/build_font.py` | сборка всех трёх начертаний (нужны `fonttools`, `numpy`, `scipy`, `Pillow`, `potrace`) |

## Стили подписи (`caption.py`)

| Группа | Стили | Что делает |
|---|---|---|
| Цвета | `classic` (белый), `yellow` (#FAC50C, как в видео), `green`, `red`, `blue`, `pink` | сплошная заливка и чёрная обводка |
| Темы | `acid` | салатовый градиент, пузыри, зелёное свечение |
| | `lava` | огненный градиент, тёмная корка с горячими краями, угольки, оранжевое свечение |
| | `sea` | от пены к глубине, световые блики воды, пузыри, голубое свечение |
| Тень | `--shadow` у любого стиля | мягкая тень вниз и вправо, в темах цветная (тёмная под цвет темы) |
| Начертания | `--weight regular / bold / extrabold` | см. файлы выше |

```bash
python caption.py "ЗАТЫКАЕТ" word.png --style lava --weight extrabold --shadow
python caption.py "ПРИВЕТ" word.png --style yellow
```
```python
from caption import render_caption
render_caption("ЖИВОЙ", style="sea", weight="bold", shadow=True).save("word.png")   # RGBA, наложить через ffmpeg overlay
```
Размер: кегль 143 px даёт высоту прописной около 100 px в кадре 1080x1920, как в исходном видео. Подпись по одному слову,
по центру, примерно на 72-75% высоты кадра.

## Откуда взяты буквы

Видео 39,5 с, подписи по одному слову (107 слов, 647 экземпляров букв). Каждая буква получена усреднением всех её
экземпляров (выравнивание по базовой линии и центру, отбор выбросов), затем векторизована. Bold и ExtraBold получены
утолщением тех же контуров (радиус 10 и 21 px при высоте прописной 600 px).

| Источник | Знаки |
|---|---|
| Из видео | А Б В Г Д Е Ё Ж З И Й К Л М Н О П Р С Т У Х Ц Ч Ш Щ Ы Ь Э Ю Я и знак «?» (сглажен) |
| Дорисовано штрихом той же толщины | Ф и Ъ (в видео их нет), цифры 0-9, знаки `. , ! : ; - — ( ) "` |
| Двойники | латинские A B C E H K M O P T X Y берутся из похожих русских букв; остальной латинице места пока нет |

Буквы с малым числом экземпляров (Ш, Э, Ц, Щ, Ё: 2-6 штук) вышли чуть грубее остальных, их стоит проверить на ваших текстах.
Цифры и знаки препинания геометричнее букв: в видео образцов не было. Если пришлёте ролик, где они есть, перерисую по нему.

## Установка и подключение

- **Windows:** правой кнопкой по `.ttf`, «Установить для всех пользователей». Названия: **Shorts Marker** (Regular, Bold) и **Shorts Marker ExtraBold**.
- **ffmpeg:**
```bash
ffmpeg -i in.mp4 -vf "drawtext=fontfile=ShortsMarker-Bold.ttf:text='ПРИВЕТ':fontsize=143:fontcolor=white:borderw=9:bordercolor=black:x=(w-text_w)/2:y=h*0.72" out.mp4
```
Темы и градиенты в `drawtext` недоступны: для них берите PNG-подписи из `caption.py` и накладывайте через `overlay`.
- **Субтитры ASS, CapCut, Premiere:** установите шрифт и выберите «Shorts Marker».

## Стиль подписи в видео

| Параметр | Значение |
|---|---|
| Кегль | 143 px при кадре 1080x1920 (высота прописной около 100 px) |
| Заливка | белая `#FFFFFF`, акцентные слова `#FAC50C` |
| Обводка | чёрная, снаружи, около 9 px (6,3% кегля), без тени |
| Положение | по центру, около 72-75% высоты кадра, по одному слову |

## Если буквы из чужого шрифта

Шрифт собран по картинке подписей. Если в вашем видео стоял чей-то платный или лицензионный шрифт, проверьте, можно ли
вам распространять его форму: это вне моего контроля.

## Пересборка

```bash
python source/build_font.py                # все три начертания
python source/build_font.py Bold           # только одно
```
Чтобы поправить букву, откройте её PNG из `source/glyphs` (чёрное = краска), сохраните и пересоберите.
